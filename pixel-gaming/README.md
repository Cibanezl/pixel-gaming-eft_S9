# 🎮 PixelGaming Store - Evaluación Final Transversal (EFT)

Aplicación web interactiva desarrollada para la asignatura **Desarrollo Frontend I (PFY2201)** en **Duoc UC**.

## 🚀 Enlaces del Proyecto
- **Repositorio en GitHub:** [https://github.com/Cibanezl/pixel-gaming-eft](https://github.com/Cibanezl/pixel-gaming-eft)
- **Demo en Vivo (GitHub Pages):** [https://cibanezl.github.io/pixel-gaming-eft/](https://cibanezl.github.io/pixel-gaming-eft/)

---

## 🛠️ Tecnologías Utilizadas
- **React 18 & Vite** (Componentes funcionales, Hooks)
- **Bootstrap 5** (Diseño responsivo, maquetación y grillas)
- **JavaScript (ES6+)** (Manipulación del DOM y lógica asíncrona)
- **HTML5 & CSS3** (Estructura semántica y personalización de estilos)

---

## ✨ Funcionalidades Destacadas
1. **Navegación Interactiva:** Interfaz responsiva con componentes `Navbar` y `Footer` maquetados con Bootstrap 5.
2. **Filtrado por Categorías:** Filtro dinámico en tiempo real (*RPG, Deportes, Estrategia, Acción*).
3. **Formulario de Contacto:** Validación de campos obligatorios y formato de email antes del envío, con alertas de estado.
4. **Carrito de Compras:** Gestión de estado global con React hooks (`useState`), cálculo automático de totales y control de duplicados.
5. **Carga Asíncrona de Datos:** Simulación de API mediante `useEffect` consumiendo datos dinámicos desde `productos.json`.

## 💻 Ejecución en Entorno Local

```bash
